## 1. 开始前的准备

| 需要什么 | 要求 | 怎么确认 |
|---|---|---|
| 电视系统 | Android 8.0 或更新 | 电视「设置 → 关于 / 系统信息」里看 Android 版本 |
| U 盘 | 200MB 以上空间，格式为 FAT32 或 exFAT | 电脑上右键 U 盘看「属性 / 显示简介」 |
| 手机 | 和电视连同一个 Wi‑Fi | 手机和电视的 Wi‑Fi 名称一样就行 |
| 电视剩余空间 | 至少 500MB | 「设置 → 存储」 |

### 选哪个安装包

到 [Releases](https://github.com/branzoom/TVbrowser2027/releases) 下载：

| 安装包 | 适合的电视 | 大小 |
|---|---|---|
| `TVbrowser2027-v1.0.1-32位.apk` | **推荐先用这个**，小米、红米等大部分电视都能装 | 约 88MB |
| `TVbrowser2027-v1.0.1-64位.apk` | 确认是 64 位系统的新电视，性能好一点 | 约 90MB |
| `TVbrowser2027-v1.0.1-通用版.apk` | 32 位版装不上、打不开时用这个，所有电视都能装 | 约 159MB |

如果电视是 Android 7 或更老的系统，这个应用装不上，会提示「解析包出错」。

> 网页打不开 GitHub 或者下载很慢的话，可以找分享给你的人要网盘链接。

## 2. 安装

### 方法一：U 盘安装（推荐）

全程用遥控器就行。不同品牌电视的菜单名称可能略有不同，找意思相近的就行。

1. **拷贝安装包**：把下载好的 apk 复制到 U 盘**根目录**（不要放在文件夹里，电视上更好找）。
2. **允许安装未知来源应用**：电视上打开「设置」，在「安全」「通用设置」「账号与安全」或「系统」里找到「未知来源」或「安装未知应用」，打开它。
   - 如果是按应用分别设置的，把第 4 步要用的「文件管理」或「媒体中心」设为允许。
   - 找不到这个开关也没关系，有些电视会在安装时弹窗询问，到时选「允许」。
3. **插入 U 盘**：插到电视的 USB 口，弹出提示可以先关掉。
4. **打开安装包**：用电视自带的「文件管理」「媒体中心」「高清播放器」或「本地媒体」打开 U 盘，选中 apk 文件，按 OK 键。
5. **确认安装**：弹出安装界面后选「安装」，等 1～2 分钟。安装包比较大，进度条走得慢是正常的。
6. **打开应用**：装好后选「打开」；以后在电视的「我的应用」或「全部应用」里找「电视浏览器助手2027」。

### 方法二：手机传到电视

不想用 U 盘，可以在手机上装一个电视助手类的 App（比如「小米电视助手」「当贝助手」），按 App 里的提示把 apk 从手机传到电视上安装。电视上同样需要先打开「允许安装未知来源应用」（见方法一第 2 步）。

### 方法三：用电脑远程安装（adb）

适合电视上找不到文件管理，或者想帮家人远程装的情况。需要电脑上有 [adb 工具](https://developer.android.com/tools/releases/platform-tools)。

1. 电视「设置 → 关于 / 系统信息」，用遥控器在「版本号」或「产品型号」上连按 OK 约 7 次，直到提示已进入开发者模式。
2. 在「开发者选项」（小米电视在「账号与安全」）里打开「USB 调试」或「ADB 调试」。
3. 在「设置 → 网络」里记下电视的 IP 地址，比如 `192.168.1.23`。
4. 电脑和电视连同一个路由器，在电脑上运行：

   ```bash
   adb connect 电视IP:5555
   ```

   电视弹出「允许 USB 调试吗？」时，勾选「一律允许」再点确定。
5. 再运行（文件名换成你下载的那个）：

   ```bash
   adb install -r TVbrowser2027-v1.0.1-32位.apk
   ```

   看到 `Success` 就装好了。

装好后建议关掉 ADB 调试，更安全。

### 升级

以后有新版本，直接按上面的方法安装新的 apk 就行，会覆盖旧版本，登录状态和收藏都会保留。

> 用过早期版本「TV浏览器助手」的朋友：新版本可以直接覆盖安装。如果你装的是更早的「电视浏览器」，新旧两个会同时存在，确认新版能用后把旧的卸载掉就行。

## 3. 第一次打开

打开应用后是首页，点一下网站卡片就能进入。第一次用，建议先登录你常用的视频网站。

**首页从上到下：**

- **右上角二维码**：手机扫码后可以在手机上输入网址、遥控电视，见[手机扫码遥控](#5-手机扫码遥控)。
- **网址输入框**：选中后按 OK 弹出电视键盘，可以输网址，也可以输关键词（用百度搜索）。电视上打字比较慢，推荐用手机。
- **我的网站**：B站、腾讯视频、爱奇艺、优酷、芒果TV、西瓜视频、YouTube、百度，点一下直接打开。
- **操作**：返回网页、收藏当前页、重新加载、电脑版/手机版、网页大小。

**登录账号（以 B站为例）：**

1. 首页点「哔哩哔哩」。
2. 用方向键把光标移到右上角的「登录」，按 OK。
3. 选「扫码登录」，用手机 B站 App 扫屏幕上的二维码，在手机上确认。

腾讯视频、爱奇艺等网站也一样，尽量用对应 App 扫码登录，比用遥控器输入账号密码快得多。登录一次后会一直保持。**会员内容需要你自己的账号有对应会员。**

## 4. 遥控器怎么用

在网页里，遥控器就是一个鼠标：方向键移动光标，OK 键点击。视频全屏后，按键会自动变成播放控制。

| 按键 | 在网页里 | 视频全屏时 |
|---|---|---|
| 方向键 | 移动光标，按住不放会越来越快 | ← → 快退 / 快进；↑ ↓ 交给网站处理（多数是调音量） |
| 光标到屏幕边缘后继续按 | 滚动光标下面的区域，弹幕列表这类小区域也能滚 | — |
| OK 键 | 点击；按住不放 = 长按 | 暂停 / 播放 |
| 返回键 | 短按回到上一页（已经是第一页时回到首页）；**长按约 1 秒直接打开首页** | 退出全屏 |
| 菜单键（≡） | 打开首页 | 退出全屏并打开首页 |
| 播放/暂停键（如果遥控器有） | 暂停 / 播放视频 | 暂停 / 播放 |

**小技巧：**

- 光标不动 8 秒会自动隐藏，随便按一下方向键就会出现。
- 点视频播放器右下角的全屏按钮进入全屏，看片体验最好。
- 菜单键不受网页影响，网页卡住时也能按。不同品牌的遥控器上，它可能印着 ≡ 或「菜单」；遥控器没有菜单键（很多 TCL 新款遥控器就没有）时，长按返回键代替。

## 5. 手机扫码遥控

手机扫一下电视首页右上角的二维码，就能在手机上打字、搜片、遥控电视，不用装任何 App。

**连接：**

1. 手机连上和电视同一个 Wi‑Fi（不要用 4G/5G 流量）。
2. 用手机相机或微信扫电视首页右上角的二维码。离得远扫不到的话，用遥控器选中二维码卡片按 OK，会弹出大二维码。
3. 手机打开页面后，顶部显示绿点和「已连接」就行了。建议把这个页面收藏或添加到手机桌面，下次直接打开。

电脑也能用：在浏览器里输入二维码旁边显示的地址，比如 `http://192.168.1.23:8765`（以你电视上显示的为准）。

**能做什么：**

| 功能 | 怎么用 |
|---|---|
| 打开网址 | 把网址贴进输入框，点「在电视上打开」 |
| 打开 App 分享的视频 | 在 B站、腾讯视频等 App 里点「分享 → 复制链接」，整段文字直接贴进来，会自动找出里面的链接 |
| 搜索片名 | 输入片名，在下面选 B站 / 腾讯视频 / 爱奇艺 / 优酷 / 百度，再点「在电视上打开」 |
| 遥控 | 播放/暂停、向上/向下翻页、重新加载、返回、回到电视首页 |
| 收藏到电视首页 | 输入网址后点「收藏」，填一个名字，电视首页会多一张卡片 |
| 看电视在播什么 | 页面顶部「电视正在看」会自动更新 |

电视切到别的应用时，从手机发网址会自动把「电视浏览器助手2027」切回前台。

注意：同一个 Wi‑Fi 下的人都能打开这个遥控页，家里用没问题，别在公共网络上用。

## 6. 设置

所有设置都在首页的「操作」一行。切换电脑版/手机版或网页大小后，应用会自动重启约 1 秒，并回到刚才的网页。

- **网页大小**：点「网页大小」选一档，从大到小依次是超大、特大、大、标准（推荐）、小、特小。越大字越大，一屏显示的内容越少。离电视远就选大一档，屏幕大就选小一档。
- **电脑版 / 手机版**：默认是电脑版，大屏看排版最舒服，也不会一直弹窗让你下载 App。某个网站显示不正常时，可以切成手机版试试。
- **收藏网站**：在网页里按菜单键回到首页，点「收藏当前页」，首页会多一张带图标和颜色的卡片。也可以从手机遥控页收藏。
- **删除网站**：在首页选中要删的卡片，按住 OK 键不放，弹出确认框后选「删除」。
- **关于 · 开源许可**：在首页最下方，可以看版本号和用到的开源软件。

## 7. 常见问题

| 遇到的问题 | 怎么办 |
|---|---|
| 安装时提示「解析包出错」 | 电视系统低于 Android 8.0，这台电视装不了；或者安装包没拷完整，重新拷一次再试 |
| 32 位版装不上，或者装上打不开 | 换通用版试试 |
| 安装时提示「禁止安装未知来源应用」 | 按「安装」一节第 2 步，打开未知来源开关 |
| 电视上找不到文件管理 | 试试「媒体中心」「本地媒体」「高清播放器」「应用商店 → 本地安装」；都没有就用手机传或 adb 远程安装 |
| 网页卡住不动了 | 按菜单键（或长按返回键）回到首页，点「重新加载」；也可以在手机遥控页点「重新加载」。电视内存不足时，应用一般会自己重新加载并弹出提示 |
| 视频有声音没有画面 | 先点「重新加载」；还不行就在播放器设置里把清晰度调低一档（比如 4K 换成 1080P） |
| 手机扫码后打不开 / 显示未连接 | 确认手机和电视连的是同一个 Wi‑Fi（手机不要用流量）；确认电视上「电视浏览器助手2027」开着 |
| 以前收藏的遥控页打不开了 | 路由器重启后电视 IP 可能变了，回到电视首页重新扫码。想一劳永逸，可以在路由器里给电视固定 IP |
| 字太大或太小 | 首页「网页大小」换一档 |
| 网站一直弹窗让下载 App | 确认首页是「电脑版网页 ✓」 |
| 要登录才能看高清 / 会员内容 | 登录自己的账号就行，会员内容需要账号本身有对应会员 |
| 遥控器按了没反应 | 光标可能隐藏了，先按一下方向键；还不行就按菜单键回首页 |

遇到表里没有的问题，欢迎在 [Issues](https://github.com/branzoom/TVbrowser2027/issues) 里反馈，请写上电视品牌型号、Android 版本，以及在哪个网站做什么操作时出的问题。
