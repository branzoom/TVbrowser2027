# 完整提示词：用 AI 做一个电视浏览器

把下面的提示词复制给 AI 编程助手，就能做出一个和「电视浏览器助手2027」差不多的应用。全程不用自己写代码。

---

## 用什么 AI 工具

普通的网页聊天 AI 只能把代码写给你，下载开发工具、编译、装到电视、看日志排查问题都得你自己来。所以要用**能在电脑上执行命令的 AI 编程助手**，这些事它都能自己做完。

| 工具 | 适合谁 |
|---|---|
| **WorkBuddy + DeepSeek 模型** | 国内用户首选，不用翻墙 |
| Claude Code | 能正常使用 Claude 的用户 |
| 其他能执行终端命令的 AI 编程工具 | 按自己习惯选 |

## 准备工作（5 分钟）

1. **电脑**：新建一个空文件夹，让 AI 在这个文件夹里工作。
2. **电视打开 ADB 调试**：在「设置 → 关于 / 我的电视」里，用遥控器在「产品型号」或「版本号」上连按 OK 约 7 次，进入开发者模式；然后在「开发者选项」（小米电视在「账号与安全」）里打开「ADB 调试」和「允许安装未知来源应用」。
3. **记下电视 IP**：「设置 → 网络」里能看到，比如 `192.168.1.23`。电脑和电视要连同一个 Wi‑Fi。

## 完整提示词

整段复制，**把电视 IP 换成你自己的**，再发给 AI：

```text
帮我做一个安卓电视用的浏览器应用，在电视大屏上直接打开视频网站的网页版看视频，不用投屏。全程和我用中文交流，应用界面也全部用中文。

【环境】
- 当前文件夹是空的，开发需要的工具（JDK 17、Android SDK、adb）请你自己下载安装到用户目录下，不要用需要管理员权限的方式
- 电视和电脑在同一个 Wi‑Fi，电视 IP 是 192.168.1.23，已经打开了 ADB 调试
- 请你直接用 adb 连接电视安装应用，自己测试、截图、看日志、修问题。电视第一次连接时会弹窗确认，提醒我去点「一律允许」
- 每完成一个阶段就装到电视上，告诉我怎么用、哪些还没测过

【浏览器内核】
- 用 Mozilla GeckoView（Maven 仓库 https://maven.mozilla.org/maven2/ 里的最新正式版），不要用系统 WebView。电视自带的 WebView 内核一般停在很多年前的版本，B站等网站的播放器会出现「有声音没画面」
- 电视内存很小（2~3GB），要省内存：所有网页共用 1 个内容进程（dom.ipc.processCount=1、dom.ipc.processCount.webIsolated=1），关闭进程预启动（dom.ipc.processPrelaunch.enabled=false），少缓存历史页面
- 网页进程被系统杀掉或崩溃时（onKill / onCrash），自动重建会话并重新打开当前网址，弹出提示「电视内存不足，页面被系统回收，已自动重新加载」；如果同一个网页 1 分钟内连续崩溃 3 次，就停止重试，回到首页提示换一个网页
- 默认用电脑版网页（桌面 UA），可以切换成手机版

【遥控器操作】
- 网页里显示一个鼠标光标：方向键移动光标，按住不放越来越快；OK 键点击，按住 OK 是长按
- 光标要发送真正的鼠标移动事件，让网页的悬停菜单能弹出来
- 光标移到屏幕边缘后继续按方向键，就用鼠标滚轮滚动光标下面的区域（弹幕列表这类局部区域也要能滚）
- 光标 8 秒不动自动隐藏，按方向键重新出现
- 视频全屏时：OK 键模拟空格（暂停/播放），左右键模拟键盘方向键（快退/快进），上下键交给网页处理，返回键退出全屏
- 返回键：短按回到上一页，已经是第一页时回首页；长按约 1 秒直接打开首页（很多遥控器没有菜单键）
- 菜单键随时打开首页，网页卡死的时候也要能用
- 遥控器上的播放/暂停键控制视频

【首页】
- 网址输入框：可以输网址，也可以输关键词（用百度搜索）
- 常用网站卡片：B站、腾讯视频、爱奇艺、优酷、芒果TV、西瓜视频、YouTube、百度。每张卡片用网站的品牌色做背景，放上网站图标
- 「收藏当前页」：收藏的网站也变成卡片，自动下载网站图标并缓存到本地，根据网址生成一个固定的背景色；选中卡片长按 OK 可以删除
- 选中的卡片要明显：放大，加白色边框和阴影，坐在沙发上也看得清
- 操作按钮：返回网页、收藏当前页、重新加载（把网页会话整个重建，卡死也能救回来）、电脑版/手机版切换、网页大小
- 网页大小：点开后从列表里选，有超大、特大、大、标准（推荐）、小、特小六档，当前这档打勾；切换后应用自动重启并回到刚才的网页
- 首页最下方放「关于 · 开源许可」，列出 GeckoView（MPL 2.0）和 ZXing（Apache 2.0）的许可信息和源码地址

【手机扫码遥控】
- 应用在电视上开一个局域网 HTTP 服务（端口 8765），电视首页右上角显示二维码（用 ZXing 生成），二维码旁边显示地址；选中二维码按 OK 弹出大二维码
- 手机扫码打开遥控网页，不用装任何 App，页面适配手机屏幕，顶部显示连接状态和「电视正在看」的网页标题
- 手机上可以：
  1. 粘贴网址，在电视上打开；也能粘贴 App 里「分享 → 复制链接」得到的整段文字，自动从中提取链接
  2. 输入片名，选 B站 / 腾讯视频 / 爱奇艺 / 优酷 / 百度，在电视上打开搜索结果
  3. 遥控按钮：播放/暂停、向上翻页、向下翻页、重新加载、返回、回电视首页
  4. 把网址收藏到电视首页，可以填名字
- 电视切到了别的应用时，手机发来网址要把浏览器切回前台
- 路由器重新分配 IP 后，二维码要自动更新成新地址

【打包】
- 最低支持 Android 8.0（minSdk 26）
- 同时输出 32 位（armeabi-v7a）、64 位（arm64-v8a）和通用版三个安装包，去掉 x86 的库来减小体积，内核的 .so 文件压缩打包
- 生成一个正式签名的密钥，签名信息放在项目根目录的 keystore.properties 里；提醒我备份密钥，丢了以后就不能覆盖升级
- 包名和应用名不要包含小米、Redmi 等商标
```

## 追加提示词（用的时候遇到问题再发）

做的过程中遇到下面这些情况，把对应那段发给 AI 就行。

**视频有声音没画面 / 网站提示浏览器版本太低**

```text
在 XX 网站播放视频时有声音没有画面。请连上电视看日志，先确认是电视解码的问题，还是网页脚本报错，再修复。
```

**网页卡死，刷新也没反应**

```text
网页卡死了，画面不动，刷新也没用。请看一下电视日志，是不是网页进程被系统杀掉了，修复后加上自动恢复。
```

**想让应用装到更多电视上**

```text
我想把这个应用装到其他品牌的电视上（比如 TCL、海信），请检查兼容性：最低系统版本、32/64 位、遥控器没有菜单键怎么办，然后写一份给普通人看的图文安装说明，包括 U 盘安装和手机传安装两种方法。
```

**某个网站显示不正常**

```text
XX 网站在电视上显示不正常（具体描述现象），请连上电视截图看一下，试试切换手机版/电脑版或者调整网页大小，找到原因再修。
```

## 小技巧

- **描述现象就行，不用猜原因**：「黑屏但有声音」「按了没反应」这样说就够了，让 AI 自己去电视上看日志。
- **一次改一两处**：每次改完装到电视上用一下，再提下一个需求。
- **卡住了就把报错原样发给它**：编译失败、连不上电视的时候，直接把报错整段复制给 AI。
- **国内网络下载慢**：AI 下载 Android SDK、GeckoView 时如果卡住了，可以让它换国内镜像，或者告诉它重试。
